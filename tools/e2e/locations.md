# Каталог тестовых локаций (Чернорусь)

Локации для E2E-сценариев, требующих конкретной геометрии мира (открытое поле, узкий
проход, лестница, помещение, дальность стрельбы и т.п.).

## Протокол пополнения (важно)

`dayz-research` каталог НЕ готовит (не видит игру). Цикл такой:

1. `dayz-tester` обнаруживает, что нужной локации нет → отчёт `BLOCKED: нужна локация
   <что нужно и зачем>` оркестратору (gap).
2. **Человек** (реальный игрок) предоставляет координаты (X/Z; высота земли Y — рантайм,
   определяется `SnapToGroundExactly`).
3. Запись добавляется сюда. `dayz-tester` использует её в сценариях.

Формат записи: имя, назначение, точки (имена + X/Z), примечания.

## ballistics-range — стрельбище (баллистика/дальность)

Открытая прямая для проверки точности и дальности огнестрела. Точка отсчёта (стрелок)
с видимостью на 500 / 800 / 1000 м по прямой.

| Точка | X | Z |
|---|---|---|
| `ref` (стрелок) | 4117 | 10827 |
| `500m` | 4388 | 10357 |
| `800m` | 4540 | 10081 |
| `1000m` | 4612 | 9955 |

Высота Y — рантайм (земля). Для LOS/стрельбы луч ведётся на высоте глаз (~1.8 м) над
землёй. Сценарий проверки чистого LOS — `tools/e2e/ballistics-los.json`.

## forest — лес (обход деревьев)

Густой лес для проверки проактивного обхода деревьев (`TickVeer` в `dmBotIntent_MoveTo`).
Бот стартует на опушке и идёт `moveto` вглубь леса (~650 м сквозь стволы).

| Точка | X | Z |
|---|---|---|
| `edge` (опушка) | 5909 | 11418 |
| `goal` (цель в глубине) | 6467 | 11739 |

Высота Y — рантайм. Сценарий — `tools/e2e/forest-avoid.json`: `spawn` → `moveto goal` →
`wait reached` (~90 с) → `assert`. PASS = бот дошёл и в RPT ноль `Tree collision`
(`[dmBot][error]`), FAIL = есть `Tree collision`.

## driving-road — дорога (вождение автомобиля)

Дорожная сеть для автотестов вождения (прямой участок, поворот, кольцо-пятиугольник).
Старт совпадает с `ref` локации `ballistics-range` (4117, 10827) — известный открытый
участок. Высота Y — рантайм (`SnapToGroundExactly`).

| Точка | X | Z |
|---|---|---|
| `start` (старт) | 4117 | 10827 |
| `straight_end` (конец прямой) | 4821 | 9616 |
| `turn_end` (конец поворота) | 4926 | 9684 |
| `ring_c` (кольцо, вершина C) | 4874 | 9863 |
| `ring_d` (кольцо, вершина D) | 4267 | 10924 |

Маршруты вождения:
- **прямая**: `start` → `straight_end`;
- **поворот**: `start` → `straight_end` → `turn_end`;
- **кольцо (пятиугольник)**: `start` → `straight_end` → `turn_end` → `ring_c` → `ring_d` →
  обратно в `start` (замкнуто).

## partial-cover — частичное укрытие силуэта (карта Nasdara)

Для проверки частичной видимости (проба-точки A/B/C/D): голова видна, грудь/плечи за
препятствием. Два кейса от человека (X/Z; Y — рантайм `SnapToGroundExactly`):

| Кейс | Точка | X | Z | Ожидание |
|---|---|---|---|---|
| 1 — только голова | `target` (цель) | 10161.85 | 11816.63 | стрелок видит **только голову** |
| 1 | `shooter` (стрелок/бот) | 10177.74 | 11837.14 | |
| 2 — голова (+плечо) | `target` (цель) | 10119.79 | 11800.63 | голова **или** голова+плечо (зависит от стойки цели) |
| 2 | `shooter` (стрелок/бот) | 10110.81 | 11766.92 | |

Использование: `spawn bot` (стрелок) + `spawn player` (цель) в этих точках, `look full` → `targetdump`
→ `visFrac` должен быть < 1 (кейс 1: ≈0.25 = 1 точка-голова; кейс 2: 0.25–0.5).

## hw-tunnel — подземный тоннель HWTunnel (карта Nasdara)

Подземный highway-тоннель для проверки затемнения (underground INNER-триггер,
`EyeAccommodation=0` → `maxDist=10`). Источник — `cfgundergroundtriggers.json` Nasdara
(триггер `HWTunnel_EastSection_Inner`, 1076 триггеров всего, 738 INNER).

| Точка | X | Y | Z | Примечание |
|---|---|---|---|---|
| `inside` (центр INNER-секции) | 5649 | **249.6** | 5685 | явный Y — внутри тоннеля (НЕ `SnapToGround`, поверхность выше) |
| `outside` (стрельбище, вне триггеров) | 4117 | 0 | 10827 | Y=0 → `SnapToGroundExactly` (поверхность) |

INNER-бокс `HWTunnel_EastSection_Inner`: центр `[5649.106, 249.628, 5684.833]`, размер
`[51.387, 11.077, 24.618]` → X∈[5623,5675], Y∈[244,255], Z∈[5672,5697]. Точка `inside`
гарантированно внутри. Для `outside` любой поверхностный участок вне тоннелей (напр.
ballistics-range) подходит.

## sandstorm-shelter — восточный кластер (карта Nasdara)

Для E2E песчаной бури (`/sandstorm start`): прямой native `Start()` на Nasdara порождает
движущийся фронт со старта ~`(18300, 0, 10000)` на запад (`dir=<-1,0,0>`). Скорость фронта =
магнитуда ветра (18 м/с при `wind 18`, иначе ~2.9 м/с — до зданий десятки минут). Здания —
только западнее X≈15000; ближайший к фронту восточный кластер — `Jakhzar`/`Marz-e Lut`/
`Varzaneh` (X≈13300–14200).

| Точка | X | Z |
|---|---|---|
| `spawn` (Jakhzar, здания рядом) | 14049 | 13397 |

Форс бури для headless: три опера моста `overcast 0.8` + `wind 18` + `sandstorm 5` (стоп — `clear`),
либо чат-команда `/sandstorm start|stop` при живом игроке. Фронт доходит до Jakhzar за ~236 с.
