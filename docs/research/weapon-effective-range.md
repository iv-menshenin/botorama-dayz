# Weapon effective range (WeaponLength × initSpeed × initSpeedMultiplier)

## Цель

Инвентаризировать весь ванильный огнестрел (винтовки + пистолеты + дробовики) и
проверить формулу «эффективной дистанции», предложенную заказчиком:

```
effective_range(м) = WeaponLength(м) × initSpeed(м/с) × initSpeedMultiplier
```

где `initSpeed` берётся из класса пули (`CfgAmmo`), а `initSpeedMultiplier` — множитель
скорости конкретного оружия (`CfgWeapons`). Цель — понять, пригодна ли формула как
эвристика дальности для ИИ-боя, и где она падает.

## Метод и цепочка маппинга

1. `CfgWeapons.<оружие>` → `WeaponLength`, `initSpeedMultiplier`, `chamberableFrom[]`,
   `magazines[]` (внутренние магазины).
2. `chamberableFrom[i]` → класс `CfgMagazines` (это либо «рассыпной патрон» `Ammo_*`,
   либо обойма/магазин `Mag_*`) → поле `ammo` → имя класса пули (`CfgAmmo`).
3. `CfgAmmo.<пуля>` → `initSpeed` (трассеры `Bullet_*Tracer` наследуют `initSpeed` родителя —
   подтверждено: ни у одного трассера нет собственного `initSpeed` в `projectiles/config.cpp`).
4. Перемножение.

Источники (читал по фактическому пути `/home/devalio/dayz/Work/DayZ Projects/DZ/...`,
копия `compatdata/830640/.../DZ`):

- `DZ/weapons/firearms/<dir>/config.cpp` — винтовки;
- `DZ/weapons/pistols/<dir>/config.cpp` — пистолеты;
- `DZ/weapons/shotguns/<dir>/config.cpp` — дробовики;
- `DZ/weapons/ammunition/config.cpp` — `CfgMagazines` (рассыпные патроны `Ammo_*`);
- `DZ/weapons/attachments/magazine/config.cpp` — `CfgMagazines` (магазины/обоймы `Mag_*`);
- `DZ/weapons/projectiles/config.cpp` — `CfgAmmo` (`Bullet_*`, `initSpeed`);
- `scripts/4_world/entities/firearms/weapon_base.c` — скриптовый дефолт `WeaponLength`.

## Ключевые факты API (подтверждено)

- **`WeaponLength` дефолт = 0.8 м** (`weapon_base.c:1313`, `InitWeaponLength()`):
  `if (ConfigIsExisting("WeaponLength")) m_WeaponLength = ConfigGetFloat(...); else m_WeaponLength = 0.8;`
  → оружие БЕЗ `WeaponLength` в конфиге получает 0.8, а не 0. Это ломает формулу для
  нескольких стволов (см. caveats).
- **`initSpeedMultiplier` в скриптах не встречается** (grep по `scripts/` пуст) — параметр
  читается движком (C++). Дефолт при отсутствии в конфиге — считаем **1.0** (гипотеза по
  физическому смыслу; отдельный канал «скорость = initSpeed × initSpeedMultiplier»).
- `chamberableFrom[]` имена — это имена `CfgMagazines` (не `CfgAmmo`); резолв калибра идёт
  через поле `ammo` магазина/рассыпного патрона.
- Внутренние магазины (`magazines[]` непустой) vs съёмные: оружие с `magazines[]={}` и
  `chamberableFrom[]` содержащим `Mag_*` (обойма) — это внутренний магазин-обойма
  (мосин, SKS, репитер, винчестер, изж-18). На эффективную дистанцию это НЕ влияет
  (калибр один), но важно для понимания «почему chamberableFrom содержит Mag_CLIP...».

## Валидация на контрольных точках заказчика

| Контроль | Формула | Ожидание | Вердикт |
|---|---|---|---|
| Мосин (`Mosin9130_Base`, `Bullet_762x54` 785, WL 1.235, ISM 1.02) | 1.235×785×1.02 = **988.9** | ≈1000 | ✅ (отклонение ~1 %, укладывается) |
| Макаров (`MakarovIJ70_Base`, `Bullet_380` 300, WL 0.19) | 0.19×300×1.0 = **57.0** | ≈50–60 | ✅ |

Обе контрольные точки сходятся → **формула валидна для винтовок и пистолетов с явным
`WeaponLength`**.

## Caveats (где формула падает)

1. **Дробовики ЗАВЫШАЮТ дальность.** `Bullet_12GaugePellets` — картечь (много дробин с
   разлётом), а формула считает её как единую пулю 340 м/с × длина ствола. Получается
   440–470 м для полноразмерных дробовиков, что физически бессмысленно (эффективно <30–50 м).
   → **дробовики классифицировать как «короткая дистанция» отдельно, формулу не применять.**
2. **`WeaponLength` отсутствует → дефолт 0.8 м** (`weapon_base.c:1313`). Затронуто 5 стволов:
   `M249`, `Trumpet`, `Groza` (OTS-14) — винтовки; `MakarovPB`, `Red9` — пистолеты.
   Для винтовок 0.8 — правдоподобно; для ПИСТОЛЕТОВ — катастрофическое завышение
   (MakarovPB 240 м против Makarov 57 м при том же патроне 9×18). **Перед расчётом надо
   проверять наличие `WeaponLength` в конфиге** (или держать отдельный справочник калибра
   → типовой длины ствола).
3. **Трассеры не отдельный калибр.** `Bullet_*Tracer` наследуют `initSpeed` родителя
   (проверено по `projectiles/config.cpp`: ни один трассер не имеет собственного
   `initSpeed`). `chamberableFrom[]` почти всегда содержит пару `<патрон> + <патрон>Tracer` —
   резолвить в ОДИН калибр.
4. **Обрезы** — смысл `initSpeedMultiplier` (напр. `SawedoffMosin9130` 0.75, `AKS74U` 0.57):
   без него обрез и полная винтовка дали бы одинаковую дальность (обрез теряет скорость из-за
   короткого ствола). Формула это учитывает, поэтому обрезы корректно «проседают».
5. **Мульти-калиберные / двойные стволы.** `B95` — двустволка, но ОБА ствола `.308`
   (`SecondMuzzle` тоже `Ammo_308Win`) — не мульти-калиберная. `Derringer` — двустволка `.357`
   (тот же калибр в обоих). Явного мульти-калиберного оружия в ванильном огнестреле НЕТ
   (пистолеты-«комбо» типа FNX45 имеют только один боевой калибр; крестовина стрел в файле
   FNX45 — это отдельный класс арбалета, не FNX).
6. **Сигнальные/не боевые**: `Flaregun` (13 м по формуле) и `speargun` (в `firearms/` без
   `config.cpp`, подводное ружьё) — вне боевой классификации.
7. **Вне скоупа** (по задаче «винтовки+пистолеты+дробовики»): арбалеты/луки (`archery/`),
   гранатомёты (`launchers/` — M79/LAW/RPG7/GP25/M203), нелетальные (`nonlethal/` —
   dartgun/shockpistol). При необходимости — отдельное исследование.

## Вывод

**Формула «рабочая» для винтовок и пистолетов с явным `WeaponLength`** (обе контрольные
точки сходятся; ранжирование по убыванию даёт адекватный порядок: болтовые снайперки →
автоматы → ПП → пистолеты). **Падает в трёх местах:**

1. **Дробовики** — завышает из-за картечи → нужен отдельный класс «короткая дистанция».
2. **Отсутствующий `WeaponLength`** → скриптовый дефолт 0.8 ломает пистолеты (MakarovPB,
   Red9). Требует проверки `ConfigIsExisting("WeaponLength")` или справочника длин.
3. **Не учитывает баллистику** (падение пули, `airFriction` в `CfgAmmo`, разброс) — формула
   даёт «потенциальную» дистанцию, а не фактическую зону уверенного поражения.

## Открытые вопросы / гипотезы

- **[нужно подтвердить]** `initSpeedMultiplier` реально домножает `initSpeed` (м/с) движком, и
  дефолт = 1.0. В скриптах поле не встречается — подтвердить эмпирически через спавн оружия и
  замер скорости пули (или принять 1.0 как конвенцию).
- **[нужно проверить]** Какую дальность для ИИ брать за «порог стрельбы» — полную
  `effective_range` или её долю (напр. ×0.5). Формула даёт «максимум», а не «эффективную зону».
- **[нужно проверить]** Для стволов без `WeaponLength` (M249/Trumpet/Groza/PB/Red9) — правдив ли
  дефолт 0.8 в рантайме (читать `GetWeaponLength()` через probe-ручку `spawnobj`), или движок
  берёт другую константу.
