# Nomad

Сейчас бродяжничество реализовано в виде двух состояний:

- dmBotState_Travel - Бродяжничество
- dmBotState_Exploration - Исследование населенного пункта

## Исследование населенного пункта

### Локация

Регистр локаций в модуле map dmWorldPOIRegistry

Чтобы определить в какой локации бот находится, нужно взять ближайшую локацию к боту, в радиусе:
- для Capital < 1200 м
- для City < 600 м
- для Village < 300 м
- прочие < 200

если в радиусе больше одного объекта - берем наименьший

### Дискаверинг объектов

Дискаверинг объектов (dmBotState_Exploration), подлежащих обходу, происходит с помощью модуля map (dmLiveBuildingRegistry) в котором уже регистрируются объекты-здания.

Изменить: сейчас dmBotState_Exploration работает на сканбоксе, нужно переключить на "живой" реестр зданий

Изменить: сейчас есть хук - конструктор зданий регисьтрирует здания в общем реестре, нужно сразу же привязывать его к локациям в модуле map

память состояния в dmExplorer (поле класса-пешки)

### Исследование

Исследование заключается в том, что бот передвигается от одного объекта к другому не повторяясь, для этого я предлагаю сразу формировать маршрут таким образом (внутри dmBotState_Exploration):

- получаем список зданий населенного пункта
- вбираем ближайшее здание
- задаем точки куда бот должен добеджать с помощью dmBuildingInteriorConfig - этот класс содержит относительные точки ВНУТРИ здания определенного класса
- по завершению обхода здание удаляется из списка зданий и процесс повторяется

### Состояние переключается в статус "Делать больше нечего"

Состояние переключается на dmBotState_Travel (любое из):

- если в списке зданий не осталось элементов
- если пройдено уже больше 90% зданий из списка
- если если пройдено уже больше 50% зданий и времени прошло больше 30 минут
- если прошло времени больше 60 минут
- если ближайшее непройденное здание дальше 500 метров

Если состояние переключено в "Делать больше нечего", то повторный вход в это состояние не выполнять

"Делать больше нечего" - это флаг объекта dmExplorer

### Список строений персистентный

Состояние должно иметь персистентный источник данных о зданиях в локации:

- Когда бот приходит на локацию, в dmExplorer делается запись о посещенных локациях (запоминает эту локацию)
- Происходит запрос в dmLiveBuildingRegistry о всех зданиях в этой локации, список сохраняется в dmExplorer
- Если состояние было сброшено и заново запущено, то dmExplorer не перезапрашивает данные о зданияхв локации, если локация не изменилась


## Бродяжничество

Вход: Если "Делать больше нечего" или бот не находится в какой то локации

### Выбор локации

Модуль map (dmWorldPOIRegistry) содержит локации - точки интереса. Поле пешки dmExplorer содержит перечень пройденных локаций.

Для следующей точки бот выбирает ближайшую локацию из тех, что еще не посетил и отправляется туда. dmExplorer сохраняет точку назначения и хранит ее, пока бот не прибудет в радиус 50 метров от этой точки. Пока бот не достиг этой точки включен флаг "Переход в локацию". Когда бот достигнет локации снимаются флаги:

- "Переход в локацию"
- "Делать больше нечего"

Локация считается достигнутой, когда бот попадает в радиус:
- для Capital < 500 м
- для City < 150 м
- для Village < 75 м
- прочие < 50


## Гейты

- dmBotState_Travel - блокируется переход когда "Переход в локацию"
- dmBotState_Exploration - блокируется переход когда "Делать больше нечего"
