Документ предлагает полностью переработать механику Fight состояния FSM бота

class dmBotState_Fighting:
    EntityAI m_TargetEntity             - это связь состояния и цели
    ref dmTarget m_Target               - это заполняется при входе, берем ссылку на цель в списке целей бота

    dmBotIntent_Approach m_IntentApproach

    Условие входа:
        Мы должны разработать единый арбитратор целей внутри бота
        т.к. выбор сражаться/сдаваться будет зависеть от личных качеств бота
        личных характеристик и уровней угрозы.
        Давай создадим у бота метод MustFight - который будет возвращать цель, которую надо поразить
        условие входа будет bot.MustFight() != NULL

    После ВХОДА:
    	запишем bot.MustFight() в m_Target и m_TargetEntity

    Алгоритм тика:
    	Нужно постоянно держать несколько Intent:
    		Смотреть на врага: LookAt - критический, параллельный
    		Приблизиться к врагу: Approach (новый) с пороговым расстоянием равным дистанции удара
    		Уворот: Evasion (новый) если противник хочет ударить, для боя с зомби упрощенный
    		Удар: HitTo (новый) постоянное желание ударить

    	Проверять все время, что цель жива и актуальна таким образом:
    	Если цель НЕ жива или 1 раз в 5 секунд:
    		Проверять bot.MustFight() и если там другая цель, то пересоздавать все Intent на нее
    		Если там пусто, то ВЫХОД

    Условия выхода:
    	bot.MustFight() - пустое



class dmBotIntent_Approach: критический, параллельный
	float m_Distance - пороговое значение
	EntityAI m_TargetEntity

	Как работает:
		вычисляем дистанцию до цели с учетом Velocity цели (если есть)
		если она больше порогового значения - приближаемся к цели
		если меньше порогового значения, то смотрим отклонение:
		  меньше 20 сантиметров - ничего не делаем
		  больше 25% - приближаемся к цели.

		для упрощения механики, можем не использовать pathfinding, если цель ближе 3 метров

class dmBotIntent_Evasion: критический, параллельный
	EntityAI m_TargetEntity

	Как работает:

class dmBotIntent_HitTo: критический, параллельный
	float m_Distance - пороговое значение
	EntityAI m_TargetEntity

	Как работает:
		Срабатывает если дистанция до цели не больше порогового значения
		Выполняет механику удара, следит за кулдауном удара, выбирает Heavy или Light
		Это управление рукопашным боем по сути
