# Вождение (driving) — статус и план продолжения

Хендофф по фиче «бот водит автомобиль» (`dmBotIntent_Drive`). Актуально на v3.208.
Работаем итеративно с человеком-наблюдателем (DISPLAY=:1).

## Что уже работает (подтверждено E2E + наблюдением)

- **Посадка** — переиспользует `dmBotIntent_GetInVehicle` (walk → дверь → сел), канал DRIVE.
- **Колёса** — `spawncar` даёт 4/4 хаба + 1 запасное (был баг «3 колеса», чинили по эталону `CivilianSedan.OnDebugSpawn`).
- **Нативный привод** — `ShiftTo(FIRST..FOURTH)` по скорости + `SetThrottle` через `modded CarScript.OnInput`. Разгон 0→47 км/ч, передачи 1→5. (Ранний вывод «сцепление не замыкается» — мискейз на 3 колёсах.)
- **Газ умеренный** — `0.6` при разгоне, rpm до ~2200 (не красная зона ~4955).
- **Руль** — нативный `SetSteering` (боковой импульс `ApplySideImpulse` убран: на грунте он толкал кузов поперёк).
- **Человеческий старт** — сел → 2 с → завёл → 5 с прогрев → трогается.
- **Маршрут из точек** — `drive` принимает `Points` (список), машина едет от точки к точке; промежуточную точку пропускает при `dist<4м ИЛИ dot<-0.2` (проехали мимо — не разворачивается назад).

## Ключевые решения (см. `docs/decisions.md`, секции `drive:`)

- Тяга — нативный привод, не импульс.
- Руль — нативный `SetSteering`, без бокового импульса.
- Нативные сеттеры ввода — только в `Transport.OnInput`.
- Канал `DRIVE` — без default-rest.
- Маршрут — явные точки (navmesh-ROADWAY на ВПП фрагментирован; `FindRoadPath`/`m_RoadFilter` оставлены для прод-патфайндера).

## Главный нерешённый баг — осцилляция «цель за кормой»

Сигнатура в `[CAR]`-логе: `angle` флапает `±3.0–3.13 рад` (±178°), `steer` замирает на
`±0.9–0.99` (полный занос), `reverse` переключается каждые ~2 с, `dist` до цели РАСТЁТ.

**Причина**: когда цель позади (dot < -0.2, угол ≈ ±π), знак cross-произведения
нестабилен → `steerTarget` мечется +1/-1 (руль в полном заносе в обе стороны), и
контроллер не может отработать разворот на 180°. `TickStuck` при этом флипает реверс.

Фикс «пропуск пройденных точек» лечит только **промежуточные** точки; на **конечной**
точке (`isLast`) и при «цель за кормой» осцилляция остаётся.

**Направление фикса (гипотеза, НЕ реализовано)**: при `dot < DM_DRIVE_PASSED_DOT`
(цель за кормой) НЕ рулить вперёд — а «по-человечески» развернуться: притормозить,
задний ход + доворот (3-точечный разворот), затем ехать к цели. Либо для конечной
точки — если уже был близко (< порог) и дистанция пошла расти, считать достигнутой.

## Вторичные проблемы

1. **«Дёрганье» на грунте** — при съезде с ВПП на грунт (низкое сцепление) машина
   заносится. Та же причина, что и выше (цель за кормой → знак руля нестабилен).
   Частично уйдёт с фиксом осцилляции.
2. **Террейн ~4244,10609** (между «Башня»/авиабаза Выбор): машина резко разворачивается
   на ~248 м от спавна — возможен склон/препятствие. Нужен probe (`spawnobj`/`scanbox`)
   или человек с координатами рельефа.
3. **Геометрия `drive-ring`**: дуга r≈20 м тесная для 16–19 км/ч → массовый проскок
   точек (dot-skip). Нужен больший радиус маршрута или ниже скорость в повороте.
4. **Флак посадки** (однократно в `drive-turn`): зависание `GetInVehicle.OnReachedGoal`
   + машина исчезла (`no such car`). Не связан с фиксом; отдельное расследование.

## Следующие шаги (по приоритету)

1. **Фикс осцилляции** (блокер): детект «цель за кормой» → человеческий разворот
   (задний ход + доворот) вместо full-lock вперёд; либо «близко был → считаем достигнутой».
2. Перепроверить `drive-turn`/`drive-ring` после фикса; при необходимости — больший
   радиус маршрута.
3. Расследовать флак посадки (`OnReachedGoal` залипание).
4. Идентифицировать террейн ~4244,10609 (нужен человек/координаты).
5. **Прод-вариант**: pathfinder по реальной дороге — пользователь найдёт полигон с
   реальной дорогой (текущая ВПП — просто ровная площадка).

## Тестовый процесс (обновление)

- Вход наблюдателя — поллингом RPT (`is connected`), не фиксированным sleep
  (`docs/ai-testing-guide.md` §6).
- Ранний стоп на аномалии: при сигнатуре осцилляции (`angle ±3 рад`, `reverse` флип,
  `dist` растёт) стопить сценарий сразу, фиксировать `[CAR]`-окно ~30–60 с + координаты
  срыва (`docs/ai-testing-guide.md` §5.4). Не ждать таймаут.

## Тестовые сценарии

`tools/e2e/drive-straight.json` (прямая по ВПП), `drive-turn.json` (90° поворот дугой
R=25), `drive-ring.json` (330° окружности R=40). Координаты — `tools/e2e/locations.md`
→ `driving-road` (это ВПП аэродрома, не автомобильная дорога).
