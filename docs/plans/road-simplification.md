# Упрощённый граф дорог (первое приближение pathfinding)

Упрощённый граф — грубый «скелет» полного `road_graph.json` для вычисления пути на
уровне населённых пунктов. Это **детерминированная производная** полного графа, а не
самостоятельный артефакт.

## Контракт (ключевое)

- **Полный граф — источник истины.** Упрощённый получается только прогоном
  `tools/simplify_road_graph.py`, руками не правится.
- **Наследование идентификации** — упрощённый граф ссылается на Id полного:
  - вершина несёт `Members` — Id узлов полного графа, которые она поглотила
    (у пункта — все его перекрёстки, у одиночного — сам);
  - ребро несёт `Path` — упорядоченные Id узлов полного графа вдоль законтраченной
    цепочки (исходный член → bend-узлы → целевой член).
- **Пропагация аппрува «рваных» дорог**: тестировщик аппрувит сегмент → сегмент
  применяется к полному графу (инкрементально, Id стабильны) → повторный прогон
  `simplify_road_graph.py` → сегмент появляется и в упрощённом (провинанс это
  доказывает). Правка упрощённого графа напрямую запрещена.

## Параметры (утверждено)

- Кластеризация перекрёстков: радиус `150 м`, порог `≥2` перекрёстка.
  → 195 пунктов + 291 одиночный перекрёсток = 486 вершин, 679 рёбер.
- Тупики (degree 1) и их «шпоры» отбрасываются (вернутся позже как POI-листья).
- Имена пунктов — пока нет (привязка к CfgLocation — отдельная задача).

## Правила контракции

1. Перекрёсток = узел полного графа с degree≥3. Кластеризация union-find по XZ
   (сетка, радиус 150 м).
2. Кластер ≥2 перекрёстков → вершина `settlement` (центроид + `Weight` = число
   перекрёстков + `Radius` = размах от центроида). Кластер из 1 → `junction`.
3. Цепочки degree-2 (`bend`) контрактируются в ребро: суммарная `Length`,
   доминантный по длине `SurfaceCategory`, длина-взвешенный `AvgFriction`, `Path`.
4. `settlement`-внутренние рёбра (между членами одного кластера) отбрасываются;
   рёбра к тупикам — отбрасываются (шпоры).

Следствие мелкого радиуса: крупные города дробятся на районы (Черногорск → ~3
вершины-района). Если нужен «один город = одна вершина» — увеличить радиус
(при R=250 м Черногорск = один кластер из 216 перекрёстков).

## Инструменты и выходы

- `tools/simplify_road_graph.py <road_graph.json> <simplified_graph.json> <out.png> [world]`
- `$profile:dmBotorama/roads/simplified_graph.json`
- `pics/road-map-simplified.png` (пункты — крупные точки ∝ Weight, одиночные — мелкие,
  рёбра цветом по покрытию, фоном бледный полный граф).

## JSON-схема

```json
{ "Version":1, "WorldName":"chernarusplus", "SourceGraph":"road_graph.json",
  "Parameters":{"clusterRadius":150.0,"minJunctions":2},
  "Nodes":[{"Id":0,"Type":"settlement","Pos":[..],"Weight":42,"Radius":180.0,"Members":[123,456]},
           {"Id":1,"Type":"junction","Pos":[..],"Members":[789]}],
  "Edges":[{"From":0,"To":1,"Length":1234.5,"SurfaceCategory":"paved","AvgFriction":0.95,
            "Path":[789,12,34,123]}] }
```
