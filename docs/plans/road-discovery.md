# Дорожный дискаверинг — дизайн (актуально)

> Зонд-«ходок» (итерация 1) отброшен: детект развилки на ходу рвал дорогу в плотных
> посёлках. Финальный подход — **граф из дорожных объектов** (memory-points), без ходьбы.

## Что уже реализовано (v3.236)

### Источник: дорожные объекты
Дороги — прокси-объекты `class=="road"` с memory-points `LB/PB` (один конец сегмента) и
`LE/PE` (другой). Детект — `dmRoadSensor.IsRoadObject` (по `MemoryPointExists(LB/PB ||
LE/PE)`, **не** через `GetLODByName` — он крашит сервер на road-прокси). Сегменты стыкуются
концами; у объекта с неполной парой конец берётся из `ClippingInfo` (bbox, long-axis=локальный Z).

### Сборка графа (`dmRoadObjectGraphBuilder`)
1. **Скан сеткой** шаг `DM_ROAD_SCAN_STEP=15` м (15/√2≈10.6 м < радиус 12 м → без дыр),
   `GetObjectsAtPosition` → `IsRoadObject`, дедуп по позиции.
2. **Сегменты** из memory-points (2 конца → ребро).
3. **Connect**: (A) слить близкие deadend'ы, смотрящие друг на друга (≤8 м, <30°);
   (B) T-сплит — deadend проектируется на середину чужого ребра (≤8 м) → junction.
4. **Метаданные** каждого ребра.
5. **Классификация** узлов по степени: `junction` (≥3), `bend` (2), `deadend` (1), `isolated` (0).

### Метаданные ребра
```json
{ "Length": 25.0, "SurfaceCategory": "dirt", "AvgFriction": 0.94,
  "Rise": 0.4, "Fall": 1.6, "Obstacles": [ {"Pos":[x,y,z], "Type":"Land_Wreck_Ural"} ] }
```
- `SurfaceCategory` — категория (`paved`/`dirt`/`gravel`/`unknown`) по имени поверхности, доминанта по точкам ребра.
- `AvgFriction` — среднее `CfgSurfaces friction` по точкам ребра (сырое, асфальт ~1.2–2.0, грунт ~0.9).
- `Rise`/`Fall` — суммарный подъём/спуск (метры) по `SurfaceY`.
- `Obstacles` — эвристика: «крупный не-дорога не-растительность (радиус>1 м) в 3 м от осевой», дедуп 3 м, с позицией+типом. **Эвристика, не точный распознаватель** (может ловить здания, пропускать мелкое) — чистится ручной разметкой.

### Разрывы (`road_gaps.json`)
Пары deadend'ов (степень 1), смотрящие друг на друга (≤`DM_ROAD_GAP_MAX=200` м, <`DM_ROAD_GAP_ANGLE=25`°).
```json
{ "Version":1, "WorldName":"chernarusplus",
  "Gaps":[ { "Id":0, "FromNode":4, "FromPos":[...], "ToNode":93, "ToPos":[...],
             "Distance":178.68, "AngleA":23.8, "AngleB":10.9, "Status":"pending" } ] }
```
`Status`: `pending` → `resolved` (соединить) / `refused` (не разрыв). Тестировщики проставляют.
Перенос в граф позже: команда читает `resolved` → идёт по прямой (снимает метаданные) → виртуальное ребро.

## Дискаверинг ВСЕЙ карты (текущая задача)

### Архитектура
- `dmRoadDiscoveryManager` (roads/4_World) — тик-автомат, вызывается из `MissionServer.OnUpdate`
  (map-модуль → добавляем `map → roads` в requiredAddons).
- **Автостарт** по define `DM_BOT_DISCOVERY` (roads/config.cpp defines[]; активен в функциональном
  билде, срезается `--prod`/`--test`).
- **Тайлы 1×1 км** по всей карте (границы из `CfgWorlds worldSize`).

### Возобновляемость (чекпоинты)
- Прогресс `discovery_progress.json` = { Version, WorldName, DoneTiles:[keys] } (список сделанных тайлов;
  возобновление — пропуском `DoneTiles`, без указателя на текущий тайл).
- Частичный граф на тайл: `tiles/<key>.json`.
- При старте: читаем прогресс → пропускаем сделанные → продолжаем; прерванный тайл пересканиваем (его нет в `DoneTiles`).
- Прогресс писать после каждого тайла.

### Финал
- Все тайлы готовы → склейка: объединить → сшить на границах (снап 2 м) → connect (merge+T-split)
  → детект разрывов → классификация.
- Выход: `road_graph.json` + `road_gaps.json` + лог `[DISCOVERY] COMPLETE` (+ итоговая статистика).
- Маркер завершения (чтобы не перезапускать на следующем старте).

### Тик-бюджет
- Скан тайла идёт порциями (несколько ячеек сетки на тик), чтобы не замораживать сервер;
  метаданные — тем же проходом. Точную гранулярность dev подбирает по бюджету (~10 мс/тик).

### Оценка
Бокс 2×2 км ≈ 1234 узла / ~35–80 с. Вся карта ≈ 59 боксов → ~30–70k узлов, ~20–60 мин (офлайн,
возобновляемо). Препятствия (GetObjectsAtPosition на сэмпл) — самая дорогая часть; при нужде
оптимизируем отдельно.

- `road_gaps.json` — разрывы (ручная разметка).
