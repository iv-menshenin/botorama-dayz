# Боевое движение (combat movement)

Движение бота во время боя: фланг (обойти укрытие), страйф (двигаться и стрелять),
укрытие/выглядывание. Реализуем по фазам — первой **фланг** (иногда его отсутствие мешает
боту стрелять).

Исследование Expansion-эталона — в `docs/research/combat.md` (раздел «Боевое движение»,
сводка `OverrideTargetPosition` / `eaistate_flank` / cover). Вывод: наш «свип + LOS-предпроверка»
точнее Expansion (у них один случайный угол без предпроверки); перенимаем только мин. дистанцию
и stall-таймаут.

---

## Фланг (Flank) — фаза 1

### Задача

Когда у бота есть враждебная цель, но НЕТ видимости (`HasLOS == false`, цель за укрытием) —
бот не стоит, а обходит цель по дуге, находит точку с видимостью и продолжает стрельбу.

### Дизайн

Новый интент `dmBotIntent_Flank` (MOVE, PARALLEL+CRITICAL) в `dmBotState_Shooting`.
Активация — через флаг `m_Active` (без удаления интентов), по образцу
`Approach`/`Evasion`/`HitTo` в `dmBotState_Fighting`.

**Триггер:** враждебная цель + `!HasLOS` + недавно видел (`m_LastContact` свежий)
+ `dist > DM_FLANK_MIN_DIST`.

**Свип углом** (одна кандидатная точка за тик, дёшево):
1. `a` от `DM_FLANK_START_ANGLE`, шаг `DM_FLANK_ANGLE_STEP`, до `DM_FLANK_MAX_ANGLE`; обе
   стороны (±a). Полный свип исчерпан → сброс + кулдаун.
2. Кандидат: `candidate = targetPos + rotate(dirБот→цель, ±a) * min(D, DM_FLANK_MAX_DIST)`.
3. Валидация:
   - снэп к навмешу `dmBotPathfinder.SamplePosition(candidate, ...)` → нет навмеша → skip;
   - гард высоты через `g_Game.SurfaceY(candidate[0], candidate[2])`: разница между высотой
     path-точки и `SurfaceY` должна быть ≤ `DM_FLANK_MAX_SURFACE_DELTA` (1.5 м), иначе skip.
4. Точка луча P = последняя точка пути, высота — **из `SurfaceY`** (не из Y навмеш-точки:
   pathfinder ошибается по высоте очень сильно) + высота кости neck бота.
5. LOS-предпроверка: рейкаст `P → голова цели`, `ObjIntersectView` (по зрению, как у `dmVision`).
6. Есть видимость → `MoveTo` до кандидата (по найденному пути).

**На ходу:** каждый тик перепроверяем LOS к цели; появился → останавливаемся раньше
(положительный сценарий), возвращаемся к обычному `Aim` (стреляем). Нет → продолжаем к точке.

**Предохранители:**
- мин. дистанция `DM_FLANK_MIN_DIST` (в упор не кружить — отходить) [из Expansion];
- stall-таймаут `DM_FLANK_STALL_TIMEOUT` — если `MoveTo` застрял/`IsFailed`, бросить и
  сбросить фланг; кулдаун `DM_FLANK_RETRY_INTERVAL` до повторного свипа [из Expansion];
- свип до `DM_FLANK_MAX_ANGLE` без результата → сброс + кулдаун.

### Константы (`cons/4_World/constants.c`)

```
DM_FLANK_START_ANGLE      = 15.0   // стартовый угол свипа
DM_FLANK_ANGLE_STEP       = 15.0   // шаг угла за тик
DM_FLANK_MAX_ANGLE        = 180.0  // предел свипа (обе стороны)
DM_FLANK_MAX_DIST         = 180.0  // кэп flankDist = min(D, 180)
DM_FLANK_MIN_DIST         = 5.0    // в упор не фланговать
DM_FLANK_MAX_SURFACE_DELTA = 1.5   // допустимая разница path-высоты vs SurfaceY
DM_FLANK_STALL_TIMEOUT    = 8.0    // таймаут зависшего MoveTo
DM_FLANK_RETRY_INTERVAL   = 8.0    // кулдаун после неудачного свипа
```

### Файлы

- `core/4_World/Entities/Bot/Intent/dmBotIntent_Flank.c` (новый).
- `core/4_World/Entities/Bot/States/dmBotState_Shooting.c` (триггер + `m_Active`).
- `cons/4_World/constants.c` (константы).
- Версия `3.34`; рефлексия в `docs/research/combat.md`.

### Проверка

`/test bot aim` с целью за стеной: бот обходит, находит точку с LOS, возобновляет стрельбу;
в упор (< 5 м) — не кружит, а отходит. Застрявший `MoveTo` → сброс фланга через таймаут (не зависает).

## Страйф (двигаться + стрелять) — фаза 2 (будущее)

Отдельная задача: `dmBotIntent_Strafe` (MOVE) по образцу `Evasion` (страйф `±90°`, корпус на
цель), гейт `HasLOS && !перезарядка && дистанция`. Связка с точностью — штраф за движение
(сейчас `strafeFactor` пропущен, техдолг H).

## Укрытие/выглядывание (вышел → выстрелил → назад на перезарядку) — фаза 3 (будущее)

Требует детекта укрытия (объект, блокирующий LOS к цели). Expansion делает это системой
(30-м бокс + классификация типов + collision-box + in-cover) — для нас переусложнено;
брать минимальный слой, когда дойдём. Связанный техдолг — опасная высота/fall-safety
(`docs/techdebt.md`).
