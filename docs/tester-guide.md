# Руководство тестировщика — команды бота

Команды вводятся в чат (начинаются с `/`). Большинство команд действуют на
**«привязанного» бота** — последнего, заспавненного через `/bot spawn ...`.

## Сводка семейств команд

| Команда | Назначение |
|---|---|
| `/bot ...` | спавн и управление ботом |
| `/fsm ...` | сборка машины состояний из черновика |
| `/test ...` | самопроверяющиеся сценарии |
| `/prof ...` | управление профайлером |
| `/tp ...` | телепорт игрока |

---

## Спавн бота

- `/bot spawn test` — заспавнить бота-тестировщика в 5 м перед игроком и привязать его.
- `/bot spawn survivor` — бот с loadout выжившего + пресет `Survivor`.
- `/bot spawn escort` — бот с пресетом `Escort`.
- `/bot spawn hunter` — бот с пресетом `Hunter`.

## Управление ботом — `/bot ...`

### Интенты (взгляд / движение / стойка)

Интенты добавляются в **командный** пул (приоритет CRITICAL), поэтому перебивают
автоматическое поведение. `/bot intent clear` возвращает бота к автомату.

- `/bot intent lookAt` — бот смотрит в точку, куда смотрит игрок.
- `/bot intent lookAtMe` — бот смотрит на игрока.
- `/bot intent goto` — бот идёт в точку, куда смотрит игрок.
- `/bot intent stance erect|crouch|prone` — держать заданную стойку.
- `/bot intent crouch` — красться (короткий интент, ~5 минут).
- `/bot intent clear` — сбросить все командные интенты.

### Патруль

- `/bot patrol add` — добавить точку патруля в точку взгляда игрока.
- `/bot patrol clear` — очистить точки патруля.

### Скорость

- `/bot speed walk|jog|sprint` — предпочтительная скорость ходьбы (1/2/3).

### Экипировка

- `/bot loadout` — список доступных loadout-пресетов.
- `/bot loadout {name}` — применить loadout к боту.
- `/bot give {item}` — выдать предмет (класс) в руки бота.

### Состояние

- `/bot status` — полный отчёт о теле/мозге бота.
- `/bot vision` — показать видимые цели бота.
- `/bot deadmans` — состояние ванильного протухания трупа (CorpseData).

### Поведение

- `/bot follow [stop]` — сопровождать игрока (бок о бок); `stop` — сброс.
- `/bot combat` — боевой режим (атакует угрозы в радиусе).
- `/bot melee` — мили-удар по текущей враждебной цели.

### Голос

- `/bot say {id}` — бот произносит голосовую реплику рядом с собой (позиционный
  3D-звук, слышен всем в радиусе; рот шевелится). `{id}` — номер реплики
  (`0` = тестовая, файл `voices/test.ogg` в PBO). См. `dmBotVoice`/`dmAISurvivorBase.SpeakLine`.

### Транспорт

- `/bot car sitdown` — сесть в машину, где сидит реальный игрок (на свободное место).
- `/bot car getout` — выйти из машины.

### Тело (значение — число)

Каждая команда принимает обязательное числовое значение.

- `/bot sethealth <float>` — здоровье.
- `/bot setblood <float>` — кровь.
- `/bot setshock <float>` — шок.
- `/bot setstamina <float>` — стамина.
- `/bot setheatbuffer <float>` — тепловой буфер.
- `/bot settoxicity <float>` — токсичность.
- `/bot setenergy <float>` — энергия.
- `/bot setwater <float>` — вода.

## FSM — `/fsm ...`

Сборка FSM из черновика (все добавленные состояния соединяются переходами между собой).

- `/fsm new` — начать новый (пустой) черновик.
- `/fsm add idle` — добавить состояние Idle.
- `/fsm add patrol` — добавить состояние Patrol.
- `/fsm add stealth` — добавить состояние Stealth (запоминает точку взгляда игрока как укрытие).
- `/fsm apply` — собрать FSM из черновика и применить его к привязанному боту.

## Самопроверяющиеся тесты — `/test ...`

Сценарий спавнит бота, присылает в чат описание + ожидаемый результат, а по таймеру
фиксирует состояние и выдаёт `PASS`/`FAIL`.

- `/test bot shock` — нокаут: бот без сознания, не двигается, приходит в себя.
- `/test bot stamina` — тяжёлый рюкзак (NailBox) + бег: вес режет кап, стамина тратится.
- `/test bot brokenleg` — перелом ноги: бот хромает, не спринтует, падает в обморок.
- `/test bot death` — Health=0: бот умирает, мозг отпускается, труп остаётся в мире.
- `/test bot target` — реактивная угроза: зомби → RegisterDamageThreat → hostile → null.
- `/test bot shoot {N}` — стрельба: заряженный АКМ + болванка-игрок → Shooting → патроны
  убывают. `{N}` — дистанция спавна бота от игрока (по умолчанию 5 м).
- `/test bot aim {N}` — лестница точности: пустой АКМ + магазины → одиночные по мишени
  на 50,100,… до `{N}` метров (по умолчанию 500); метрика — выстрелов до убийства.
- `/test bot emote {id}` — эмоция по `EmoteConstants` ID (напр. 44=salute, 12=dance, 40=point).
- `/test bot fight` — бой: бот с Machete отбивает 3 волны зомби (спереди + сзади).
- `/test bot weapon load` — зарядка оружия: B95 (пачка .308) и M4 (магазин STANAG).
- `/test bot weapon selection` — выбор оружия: игрок → огнестрел, зомби → мили.
- `/test bot looting get` — подбор: бот по очереди поднимает с пола 7 предметов одежды
  (куртка, штаны, кепка, перчатки, шемаг, ботинки, повязка); проверяет, что каждый НАДЕТ
  в свой слот (Body/Legs/Headgear/Gloves/Mask/Feet/Armband).
- `/test bot looting change` — смена одежды: бот в шортах/футболке/обуви (в карго груша/яблоко)
  поднимает горку-штаны и горку-куртку; проверяет, что новая одежда надета в слоты Legs/Body,
  а карго (груша/яблоко) перенесено.
- `/test bot suppressor` — глушители: 4 фазы силы шума выстрела через
  `dmBotGunshotNoiseStrength()` — без глушителя 3000 м, самодельный (`ImprovisedSuppressor`)
  150 м, автоматный (`M4_Suppressor`) 100 м, пистолетный (`PistolSuppressor`, на CZ75) 75 м.
  Проверяет, что сила выстрела определяется по типу глушителя, а не по типу оружия.
- `/test bot trajectory` — траектория пули: мосинка (`Mosin9130`) + 1 патрон в патроннике,
  идеальный прицел (`SetPerfectAim`), цель-болванка на 500 м по взгляду игрока, один выстрел
  без FSM (`GetAiming().SetTarget` + `Enable` → `RaiseWeapon` → `RequestFire`). Время полёта —
  дельта в логе `[Ballistics]` (FIRE → HIT / IMPACT, домен `DM_BOT_DEBUG_BALLISTICS`).

### Лечение (MedicalCare) — `/test bot ...`

Каждый сценарий выдаёт боту полную аптечку (штаны со всеми медикаментами), запускает чистый
пресет Idle + MedicalCare, накладывает эффект и ждёт, пока бот сам вылечится (с анимацией).
Логи — домен `DM_BOT_DEBUG_MEDICAL` (включи в `config.cpp` `defines[]`, если нужно видеть шаги очереди).

- `/test bot bandaging` — рана (Pelvis): бот перевязывается → `IsBleeding()==false`.
- `/test bot splinting` — перелом ноги: бот накладывает шину → `GetBrokenLegs()==BROKEN_LEGS_SPLINT`.
- `/test bot painkiller` — перелом + обезбол: после шины бот пьёт обезболивающее → `MDF_PAINKILLERS` активен.
- `/test bot painkillerbandage` — рана + низкое HP (30): после перевязки (HP<75%) обезбол → `MDF_PAINKILLERS` активен.
- `/test bot charcoal` — отравление: бот принимает активированный уголь → `MDF_CHARCOAL` активен.
- `/test bot tetracycline` — грипп: бот принимает тетрациклин → `MDF_ANTIBIOTICS` активен.
- `/test bot vitamins` — холод (HeatComfort≤-0.15): бот принимает витамины → `MDF_IMMUNITYBOOST` активен.

### Ручные сценарии `/test`

- `/test bot patrol` — бот с маршрутом из трёх точек (повороты: назад 50 м, вправо 90° 50 м, вправо 135° 100 м).
- `/test bot overload prepare {N}` — заспавнить N ботов в радиусе 15 м (по 25 точек патруля, случайная скорость).
- `/test bot overload run` — собрать и запустить FSM (patrol + idle) на подготовленных ботах.
- `/test bot enemy {N}` — заспавнить бота в N метрах от игрока (лицом к нему), одетого в горку
  (штаны/куртка/перчатки/ботинки), с B95 и патронами .308; игрок-отправитель — враг бота.

### Отмена

- `/test cancel` — отменить последний тест игрока.
- `/test cancel last` — то же, что `/test cancel`.
- `/test cancel all` — отменить все тесты игрока.

## Профайлер — `/prof ...`

Управление накоплением замеров (`dmBotProfiler`).

- `/prof dump` — записать замеры в CSV (`$profile:dmBotorama/profile/profile_HH-MM-SS.csv`); путь — в чат.
- `/prof clear` — сбросить накопленные замеры (не выключая профилирование).
- `/prof start` — включить накопление (включено по умолчанию с загрузки).
- `/prof stop` — выключить накопление.

Типичный цикл замера сценария:
`/prof stop` → `/prof clear` → `/prof start` → `<сценарий>` → `/prof stop` → `/prof dump`.

## Телепорт — `/tp ...`

- `/tp me {X} {Z}` — телепортировать **игрока** в точку с координатами X/Z (прибивает к земле).
