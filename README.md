# botorama

Серверный ИИ-бот для DayZ (мод, префикс классов `dm`). Автономные «выжившие»,
управляемые конечным автоматом и иерархией интентов: перемещение, взгляд, эмоции,
стойка, удар, стрельба, лут.

## Что это

Бот — связка «мозг + пешка»:

- `dmAISurvivor` — мозг: поведение, FSM, восприятие, память целей, инвентарь/лут.
- `dmAISurvivorBase : PlayerBase` — пешка: тело, движение, анимации, оружие.

## Как устроено

- **FSM** (`dmBotFSM` + `dmBotState`) — высокоуровневые состояния (Idle / Shooting /
  Fighting / Follow / Exploration / Patrol и др.), переходы декларативные
  (`Require` / `BlockWhen`, приоритеты, cooldown повторного входа).
- **Интенты** (`dmBotIntent*`) — арбитраж по каналам (движение, взгляд, эмоция, стойка,
  удар) с приоритетами; три пула — FSM / личный / командный.
- **Восприятие** — зрение (`dmVision`, raycast-LOS) и слух (`dmHearing`, шум) → память
  целей `dmTarget` с threat-оценкой.
- **Навигация** — pathfinding по NavMesh, двери, лестницы, перелезание.
- **Бой** — огнестрел с моделью точности `dmAiming` (личный разброс) + оружейный dispersion
  из конфига, режимы огня (одиночный / очередь / авто / двойной ствол), мили.
- **Лут / инвентарь** — TidyInventory (стек патронов / перезарядка), подбор предметов, одежда.
- **Тесты** — `/test bot ...`: самопроверяющиеся сценарии (стрельба, выбор оружия, зарядка
  и т.д.) на собственном каркасе `dmTestSuite`.

## Модули

- `cons/` — константы (game / world / mission-слои).
- `core/` — код мода (`3_Game` / `4_World` / `5_Mission`).
- `reg/` — `modded class`-патчи ванильных классов (`Weapon_Base`, `WeaponFire`, `PlayerBase`).
- `loadout/` — пресеты экипировки.
- `test/` — тестовый каркас и сценарии.
- `docs/` — документация (`codeguide.md`, `combat.md`, `research/`).
